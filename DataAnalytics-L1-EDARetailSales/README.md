# EDA on Retail Sales Data

## Objective

Perform Exploratory Data Analysis (EDA) on retail sales data to discover sales trends, customer behavior patterns, and business insights.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

Sample Superstore Dataset

## Analysis Performed

- Dataset Inspection
- Missing Value Analysis
- Descriptive Statistics
- Monthly Sales Trend Analysis
- Quarterly Sales Trend Analysis
- Revenue by Category
- Correlation Heatmap
- Regional Sales Analysis
- Customer Segment Analysis

## Key Insights

- Technology category generated the highest sales.
- Quarterly sales display seasonal fluctuations.
- Regional performance varies significantly.
- Discounts may negatively affect profitability.

## Conclusion

Business recommendations were provided based on the findings to improve inventory planning, marketing strategy, and profitability.
